 INSTALLATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Install Python dependencies:
     $ cd trustlens
     $ pip install -r requirements.txt

  2. OPTIONAL: Install scanners (for full pipeline):
     macOS:   $ brew install checkov trivy semgrep
     Linux:   $ pip install checkov; ... (see INSTALLATION.md)

  3. Verify:
     $ python test_pipeline.py    # Test without scanners
     $ python main.py ./sample_repo  # Full scan

 BASIC COMMANDS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Scan default location:
  $ python main.py

  Scan custom repo:
  $ python main.py /path/to/repo

  Scan with custom output:
  $ python main.py /path/to/repo /path/to/findings.json

  Test without scanners:
  $ python test_pipeline.py

  View results:
  $ python -m json.tool findings.json | less

 WHAT YOU GET
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Step 1 - SCANNING:
    ✓ Checkov (Infrastructure misconfigurations)
    ✓ Trivy (CVE vulnerabilities)
    ✓ Semgrep (Code patterns / SAST)

  Step 2 - NORMALIZATION:
    ✓ Unified Finding Model (UFM)
    ✓ Severity normalization
    ✓ Deduplication
    ✓ JSON output

  OUTPUT FILE: findings.json
    - One JSON object per finding
    - 11 fields per finding
    - Sorted by severity
    - Ready for further processing

 COMMON OPERATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Count findings by severity:
  $ python -c "
  import json
  with open('findings.json') as f:
      findings = json.load(f)
      for severity in ['CRITICAL', 'HIGH', 'MEDIUM', 'LOW']:
          count = sum(1 for x in findings if x['severity_raw'] == severity)
          print(f'{severity}: {count}')
  "

  Find findings in specific file:
  $ python -c "
  import json
  with open('findings.json') as f:
      findings = json.load(f)
      for f in findings:
          if 'app.py' in f['location']['file']:
              print(f\"{f['severity_raw']} | {f['title']}\")
  "

  Filter by severity:
  $ python -c "
  import json
  with open('findings.json') as f:
      findings = [x for x in json.load(f) if x['severity_raw'] == 'CRITICAL']
      print(json.dumps(findings, indent=2))
  " > critical_only.json
